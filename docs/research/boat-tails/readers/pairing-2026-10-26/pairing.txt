2. The rule

    Two values agree when their difference is within the two stated errors
    summed, on each coordinate: |xA - xB| <= ex(A) + ex(B) and |yA - yB| <=
    ey(A) + ey(B). A pair that fails on either coordinate is a disagreement.
    The values and the errors are used as each reader printed them.

    The stated errors are those in each row's note ("reading error x +-...,
    y +-..." for A, "read error x +-..., y +-..." for B). Where an error is
    printed as zero, zero is used: B TN 3819 fig. 21, y error printed as
    zero in 1 row; B TN 3372 fig. 10, x error printed as zero in 31 rows.
    Where a row with a value states no error, zero is used: B RM E51F26 fig.
    29, no x error in 6 rows; B RM E51F26 fig. 30, no x error in 5 rows; B
    TN 3372 fig. 12, no x error in 60 rows (these are curve rows whose x is
    a station the reader chose and read at).

    Because some stated errors are smaller than the printed rounding of the
    values, each disagreement also says whether it would fall within the
    summed errors plus half a unit in the last printed digit of each value
    ("within printed rounding"). That note does not change the verdict.

    Matching. Within each figure panel, symbol points are matched by
    position: the cost of a candidate pair is its distance in units of the
    summed errors, sqrt((dx/(ex(A)+ex(B)))^2 + (dy/(ey(A)+ey(B)))^2), plus 3
    when the two readers name a different symbol; pairs farther than 12 such
    units are not allowed; the set of pairs with the least total cost is
    taken (optimal assignment). Points read on a drawn curve pair only with
    the same curve at the same station (stations within the summed x
    errors); a curve sampled at different stations by the two readers
    therefore leaves points read once by each, which is not a missing point.
    Rows left empty pair with the other reader's row on the same curve or
    series at the same station. Every other row is read once.

    Labels. For every pair the readers' series, configuration, Mach number
    (where the x axis is not the Mach number), coefficient and its
    reference, and page are reduced to the facts they state and compared. A
    difference is "differ" when both state the fact differently, and "stated
    by one only" when one reader states it and the other does not in that
    row. Differences in wording alone are not listed.
