# TN D-4014 figs. 5 and 6, CA at alpha 0: second reading, method

Source: NTRS 19670020031.pdf, PDF pages 25 (5a, config 1 fins off), 28 (5b, dF 0), 31 (5c, dF 2), 34 (6a, config 2 fins off), 37 (6b, dF 0), 40 (6c, caption reads dF = -2 deg; the list of figures says 2 deg). Rendered with pdftoppm at 300 dpi, the native resolution of the 1-bit CCITT scans. Done before opening the first agent's readings.

Axis calibration, per panel:
- alpha: vertical grid lines found by column-darkness profiles (scripts/lines.py) in an upper and a lower band; labelled ticks -8, -4, 0, 4, 8 identified against the printed labels (checked on zoom views). Lines lean by 1.5 to 9 px over the plot height, so the alpha = 0 line was interpolated to the height of each row.
- CA: horizontal lines from row profiles. Labelled ticks .1 to .6 checked against printed labels (label digit mid-heights are typed and scatter by +-3 px, so they were used only to identify lines, not to place them). Where the 1-bit scan lost the horizontal lines near alpha 0 (pages 25, 28, 31), the lines were taken from the nearest band where they survive and carried across with the tilt measured from the frame line or upper lines: p25 none (lines level within 0.5 px over x 1175 to 1815; +-2.5 px allowed), p28 -1.0 px, p31 -2.0 px. Pages 34, 37, 40 have grid lines visible at alpha 0 and were calibrated locally. Scale: 139 to 141 px per 0.1 CA (config 1 panels), 113 to 117 px per 0.1 (config 2 panels).

Points read: the faired curve height at alpha 0 for M = 1.50, 1.80, 2.30, 2.96 (config 2 has no M = 1.50 data), from row profiles in narrow x-bands in the gaps between the symbols at alpha about -1, 0, +1 (scripts/bandprof.py, lines.py), checked against the symbol bounding-box centres on 3x to 4.5x zoom views (scripts/view.py). The curve is flat at alpha 0 (it is the minimum), so the value is insensitive to the exact alpha. Where the curve and symbol centre differ (5b M 2.30: 0.3798 vs 0.3820; triangles generally) the curve value is given and the difference is folded into the error.

Estimated error: +-0.0013 to +-0.0025 CA per value (reading +-1.5 to 3 px plus calibration +-1 to 2.5 px), listed per row in the CSV. These exclude the reports' own stated accuracy (+-0.004).
